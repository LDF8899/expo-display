# 专题页面素材调用说明

本文档说明系部专题页面（`static/pages/department-*.html`）的素材来源、提取流程与调用链路，供内容维护与二次开发参考。

## 1. 调用链路总览

```text
原始素材（uploads/，网盘分发，不进 git）
   │  scripts/extract_docx_assets.py（从 docx 提取内嵌图片）
   ▼
static/pages/generated/<专题>/imgNNN.ext     ← 提取产物（进 git）
   │  ① 被 data 文件引用
   ▼
static/pages/department-<专题>.data.js       ← 结构化内容数据（DEPARTMENT_DATA）
   │  ② 被 department-detail.js 读取渲染
   ▼
static/pages/department-<专题>.html          ← 页面（主页面 + 二级内容中心）
   │  ③ 主页面卡片背景图由 JS 自动替换为 data 中的真实图片
   ▼
浏览器展示（主页面 4 板块 + 二级详情）
```

## 2. 素材来源与提取

- 原始素材包：`bijie-materials.zip`（网盘分发），解压后放到项目根目录 `uploads/`，保持原有结构。
- `uploads/` 整体被 `.gitignore` 排除，**不进 GitHub**；换机/部署时需先从网盘恢复。
- 提取脚本：`scripts/extract_docx_assets.py`

  ```bash
  python scripts/extract_docx_assets.py
  ```

  作用：解析 `uploads/` 下各专题 docx 的段落与内嵌图片对应关系，把图片提取到
  `static/pages/generated/<专题>/imgNNN.ext`（按文档内出现顺序编号），
  并在 `scripts/.docx_parsed/<专题>.json` 生成「段落文本 + 图片 URL」映射（不入 git，供人工挑选素材时对照）。

- 提取产物 `static/pages/generated/` **进入 git**（页面图片依赖，约 190MB；其中 mp4 视频未被页面引用，已 gitignore，原始文件在 uploads）。

## 4. 数据结构说明（DEPARTMENT_DATA）

data 文件定义 `window.DEPARTMENT_DATA`（现代农业沿用 `window.AGRI_DATA`，`department-detail.js` 优先读 `DEPARTMENT_DATA`）：

```js
window.DEPARTMENT_DATA = {
  "groups": [
    {
      "id": "base", "title": "基本情况", "note": "院系概览",
      "sections": [
        {
          "title": "专题概况",               // 二级中心里的分类（筛选器显示）
          "items": [
            {
              "title": "系部简介：xxx",      // 条目标题
              "summary": "摘要…",            // 卡片摘要
              "body": ["正文段落1", "正文段落2"],  // 详情弹窗正文（每元素一段）
              "imgs": ["/static/pages/generated/xxx/img001.jpeg", …]  // 图片（第 1 张作封面）
            }
          ]
        }
      ]
    },
    // …coop（含"人物风采"分类）、achv（含"新闻动态""事件活动"分类）、media（视频资源，留空时由页面 video-box 兜底）
  ]
}
```

- `item.imgs[0]` 作为卡片/详情封面；详情弹窗展示第 1 张为背景大图、第 2~5 张为画廊。
- 分类（`section.title`）会出现在二级中心的筛选器里；点击面板即打开该板块的二级详情。

## 5. 图片自适应展示

- 二级中心卡片/大图/弹窗图：`background-size: cover` 等比缩放居中（自适应容器，不拉伸变形）。
- 主页面卡片 `.photo` 背景：`department-detail.js` 的 `applyPagePhotos()` 启动时按板块自动取 data 中图片替换占位背景图（同 `cover` 自适应）。
- 注意：内联样式中的图片 URL 一律使用**单引号** `url('…')`（见 `cssImage()`），双引号会截断 HTML 属性导致图片不显示。

## 6. 按专题配色（主题色）

- 颜色集中在 `department-detail.css` 的 `:root` CSS 变量（`--detail-forest`、`--detail-gold`、`--detail-canvas`、`--detail-veil` 等 25 个），默认深绿。
- 每个专题 HTML 在 `<link department-detail.css>` 后插入 `<style id="detail-theme">`，覆盖 `.department-detail-center` 的变量即整体换色：

| 专题 | 主色 | 风格 |
|---|---|---|
| 数字文旅 | #1d5c72 | 青蓝山水 |
| 智慧康养 | #a04a5c | 暖玫红 |
| 财经商贸 | #2c5f8a | 商务蓝 |
| 智能制造 | #3d5a6e | 钢蓝灰 |

调整某专题配色：改对应 HTML 里 `detail-theme` 样式块中的变量值即可。

## 7. 注意事项

1. **uploads 恢复**：部署/换机后需从网盘恢复 `uploads/` 才能重新提取素材；`static/pages/generated/` 已随仓库分发，页面图片不依赖 uploads。
2. **mp4 视频**：数字文旅目录下的 2 段视频已复制到 `generated/digital-tourism/` 但未被页面引用（媒体板块留空走页面 video-box 兜底），且已加入 `.gitignore`（`static/pages/generated/**/*.mp4`）；如需播放视频，请在 data 文件 media 板块补充条目并在前端接入播放器。
3. **现代农业数据**：`department-modern-agriculture.data.js` 使用旧变量名 `AGRI_DATA`（兼容保留）；其图片路径曾指向不存在的 `/uploads/blueprint/...`，已替换为 `generated/modern-agriculture/` 真实图片。
4. **更新素材流程**：替换/更新 uploads 中 docx → 运行 `scripts/extract_docx_assets.py` 重新提取图片 → 依据 `scripts/.docx_parsed/<专题>.json` 的段落-图片映射人工更新 data 文件正文与 `imgs` → 刷新页面验证。
